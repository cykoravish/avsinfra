# Home Page — Review Notes (v1 → v2)

## Found issues
1. **Hero** — bottom skyline bars feel random/disconnected, floating awkwardly with no ground/fade. No ambient depth.
2. **Belief section** — right column text is fine, but section reads flat and leaves excess empty space below on tall screens; no visual counterpart to the claim.
3. **About section** — big dead gap between the intro text (left) and empty right column before stats. Wastes the most valuable "about" real estate.
4. **General** — sections rely only on text; no supporting numerals/graphics that reinforce the "clean air / breathable" story visually (beyond the hero glow).
5. Minor: hero CTA row sits close to skyline illustration.

## Fixes applied in v2
1. Hero — redesigned skyline into a cleaner silhouette anchored to bottom edge with proper gradient fade; added floating "air particle" dots for atmosphere; adjusted spacing so CTA never collides with illustration.
2. Belief — added a right-side "AQI comparison" visual card (Delhi NCR avg vs AVS community air quality concept) so the column is never empty and the claim becomes visual, not just text.
3. About — replaced the dead gap with a stat-card visual cluster (decorative "Est. 2014" badge + accent ring) beside the copy, before the full-width stats row.
4. Consistent breathing-glow ambient blobs extended tastefully to Belief/About for continuity (kept subtle, not overused).
